# Keepaza Website

This is a React website I built for Keepaza. The project is a landing page designed to introduce the Keepaza platform and its payment features.

I built it using React and CSS, with separate components for the different sections of the website. I also worked on making the page responsive so it can be viewed on both desktop and mobile screens.

## How to Install and Run the Project

Follow these steps to run the project on your computer.

### 1. Clone the repository

git clone https://github.com/emmy3oy/keepaza-website.git

### 2. Open the project folder

cd keepaza-website

### 3. Install dependencies

Make sure you have Node.js and npm installed, then run:

npm install

This installs all the packages needed to run the project.

### 4. Start the development server

npm run dev

Vite will provide a local URL, usually:

http://localhost:5173/

Open that URL in your browser to view the website.

## Build for Production

To create a production build, run:

npm run build

To preview the production build locally:

npm run preview
